项目定位

agent-evolve 把「进化学习」从平台特性变成开源工具：扫描对话历史 → 按频率与纠错模式统计信号 → 生成带证据链的提案 → 人工审批 → 备份应用 → 台账回滚。任何智能体（OpenClaw、Claude Code、自研 Agent）都可以挂载使用。

它解决三个问题：会话失忆（偏好反复交代）、噪音沉淀（单次提及当长期规则）、黑箱学习（悄悄改自己，不可审计）。

核心流程

扫描history/ 对话日志
关键词命中 + 触发词分类
→
统计score = Σ(次数 × 权重 × 时间衰减)
→
提案过阈值 + 去重
附证据链
→
审批人类 approve
写入台账
→
应用备份 → 合并
进受保护文件
→
回滚从备份恢复

发现全自动，写入永远需要人类批准。这是本项目不可妥协的安全红线。

信号模型

信号含义权重示例
correction用户主动纠正1.0说了别用冒号，你又用了
explicit明确要求记住1.0以后报告都用表格
repeat跨会话重复提及0.7配图要白底（多次提到）
acceptance采用且零纠正（弱信号）0.3某种格式从未被纠正

时间衰减：近 30 天权重 1.0，每 30 天衰减，最低 0.2，防止陈旧偏好长期占位。

CLI 一览

evolve init            # 初始化工作区
evolve scan            # 扫描对话，输出信号统计
evolve propose         # 过阈值主题生成提案
evolve list            # 列出提案与状态
evolve approve <id>    # 人工批准（写台账）
evolve reject <id>     # 拒绝（保留原因）
evolve apply <id>      # 备份 + 合并 + 台账
evolve rollback <id>   # 从备份恢复

设计要点

🔒 发现与写入分离

scan / propose 可 cron 全自动；apply 前必须有人类 approve，且全程留痕。

📁 文件即状态

信号、提案、台账、备份全是普通文件，git 友好，可审计、可手工修复。

🧩 平台无关

纯 CLI + 文件，任何能读写文件、执行命令的智能体都能挂载。

🧾 证据链

每条提案附信号样本（类型、原文引用、来源文件），人类可逐条核查。
